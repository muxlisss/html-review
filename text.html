Chapter 2

Text formatting tags

These tags change the meaning or the look of text.

Beginner

<strong> and <em>

Definition

<strong> marks very important text (bold) and <em> marks emphasis (italic).

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<p>This is <strong>very important</strong> and <em>emphasized</em>.</p>

Example (result)

This is very important and emphasized.

<mark>, <del>, <ins>

Definition

<mark> highlights, <del> shows removed text and <ins> shows added text.

Attributes

Attribute Role
cite URL explaining the change (del, ins)
datetime Date of the change
class / id Global attributes: name the element so CSS can style it

Example (code)

<p>Price: <del>20$</del> <ins>15$</ins>, <mark>on sale</mark></p>

Example (result)

Price: 20$ 15$, on sale

<sub> and <sup>

Definition

<sub> lowers text and <sup> raises text.

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<p>H<sub>2</sub>O and x<sup>2</sup></p>

Example (result)

H2O and x2

<blockquote>, <q>, <abbr>

Definition

<blockquote> is a long quote, <q> a short inline quote and <abbr> an abbreviation.

Attributes

Attribute Role
cite Source URL of the quote
title (abbr) Full text shown on hover
class / id Global attributes: name the element so CSS can style it

Example (code)

<blockquote>Learning never stops.</blockquote> <p>He said <q>hello</q>. We use <abbr title="HyperText Markup Language">HTML</abbr>.</p>

Example (result)

Learning never stops.

He said hello. We use HTML.

<code> and <pre>

Definition

<code> shows computer code and <pre> keeps spaces and line breaks.

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<pre><code>let x = 5; let y = 6;</code></pre>

Example (result)

let x = 5; let y = 6;

Quick Recap

strong and em give importance, mark highlights, sub and sup lower or raise text, and blockquote, q and code quote text or code.
