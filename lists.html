Lists

Lists group related items.

Easy

<ul> and <li>

Definition

<ul> is an unordered (bullet) list and <li> is one item of a list.

Attributes

Attribute Role
type (old) Bullet style, use CSS instead
class / id Global attributes: name the element so CSS can style it
```html

Example (code)

<ul> <li>Forget to close a </li> <li>Refresh the page 47 times</li> <li>Blame the computer</li> <li>Google the same error 12 different ways</li> <li>Add !important and hope for the best</li> <li>Celebrate when "Hello World" finally appears 🎉</li> </ul>

Example (result)

<dl>, <dt>, <dd>

Definition

A description list: <dt> is the term and <dd> is its description.

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<dl> <dt>HTML</dt> <dd>Structure of a page</dd> <dt>CSS</dt> <dd>Style of a page</dd> </dl>

Example (result)

HTML
Structure of a page
CSS
Style of a page

Quick Recap

ul is a bullet list, ol is a numbered list, li is an item, and dl groups terms with descriptions.
