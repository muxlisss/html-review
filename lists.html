Chapter 4

Lists

Lists group related items.

Easy

<ul> and <li>

Definition

<ul> is an unordered (bullet) list and <li> is one item of a list.

Attributes

Attribute Role
type (old) Bullet style, use CSS instead
class / id Global attributes: name the element so CSS can style it

Example (code)

<ul> <li>HTML</li> <li>CSS <ul> <li>Flexbox</li> </ul> </li> </ul>

Example (result)

  • HTML
  • CSS
    • Flexbox

<ol>

Definition

An ordered (numbered) list.

Attributes

Attribute Role
type Numbering style: 1, A, a, I, i
start First number
reversed Counts down

Example (code)

<ol type="A" start="3"> <li>Third</li> <li>Fourth</li> </ol>

Example (result)

  1. Third
  2. Fourth

<dl>, <dt>, <dd>

Definition

A description list: <dt> is the term and <dd> is its description.

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<dl> <dt>HTML</dt> <dd>Structure of a page</dd> <dt>CSS</dt> <dd>Style of a page</dd> </dl>

Example (result)

HTML
Structure of a page
CSS
Style of a page

Quick Recap

ul is a bullet list, ol is a numbered list, li is an item, and dl groups terms with descriptions.
