Chapter 8

Semantic and layout tags

Semantic tags describe the role of each part of a page.

Medium

<header>, <nav>, <footer>

Definition

<header> is the top of a page or section, <nav> holds main links and <footer> is the bottom.

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<header><h3>My site</h3></header> <nav><a href="index.html">Home</a></nav> <footer><p>Copyright 2026</p></footer>

Example (result)

My site

Home

Copyright 2026

<main>, <section>, <article>, <aside>

Definition

<main> is the main content, <section> a theme, <article> independent content and <aside> side content.

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<main> <section> <article><p>A blog post</p></article> <aside><p>Related links</p></aside> </section> </main>

Example (result)

A blog post

Related links

<div> and <span>

Definition

<div> is a block container and <span> is an inline container. Both have no meaning by themselves.

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<div class="box"><p>A block with a <span class="hl">word</span> inside.</p></div>

Example (result)

A block with a word inside.

Quick Recap

header, nav, main, section, article, aside and footer give meaning to the layout. div and span are neutral containers.
