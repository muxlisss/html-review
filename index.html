<html>, <head>, <body>

Definition

<html> wraps the whole page, <head> holds information about the page and <body> holds what visitors see.

Attributes

Attribute Role
lang Language of the page
charset (on meta) Character encoding, usually UTF-8
class / id Global attributes: name the element so CSS can style it

Example (code)

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>My page</title> </head> <body> <p>Hello, web!</p> </body> </html>

Example (result)

Hello, web! Only the content of the body is displayed.

<h1> to <h6>

Definition

Headings from the most important (h1) to the least important (h6).

Attributes

Attribute Role
align (old) Text alignment, replaced by CSS
class / id Global attributes: name the element so CSS can style it

Example (code)

<h1>Main title</h1> <h2>Section</h2> <h3>Sub-section</h3>

Main title

Section

<p>, <br> and <hr>

Definition

<p> makes a paragraph, <br> forces a line break and <hr> draws a horizontal line.

Attributes

Attribute Role
width (hr, old) Line width, replaced by CSS
class / id Global attributes: name the element so CSS can style it

Example (code)

<p>First line<br>Second line</p> <hr> <p>New paragraph</p>

Example (result)

First line
Second line

New paragraph

Quick Recap

A page has html, head and body. Headings give titles, p makes paragraphs, br breaks a line and hr draws a line.
