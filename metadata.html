Chapter 9

Metadata

Metadata gives information about the page to browsers and search engines.

Medium

<meta> and <title>

Definition

<meta> gives information about the page and <title> sets the tab title.

Attributes

Attribute Role
charset Character encoding
name Type of info: author, description, viewport
content Value of the info
http-equiv Pragma directive

Example (code)

<meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <meta name="author" content="Student"> <title>My page</title>

Example (result)

Nothing is displayed: metadata lives in the head. Look at the title in the browser tab.

<link> and <base>

Definition

<link> connects an external file and <base> sets the base address of all links.

Attributes

Attribute Role
rel Relation, for example stylesheet
href Path of the file
type File type
target (base) Default target of links

Example (code)

<link rel="stylesheet" href="css/style.css">

Example (result)

Nothing is displayed: this very page uses this tag to load its style.

Quick Recap

meta describes the page, title names it and link connects files such as CSS. All of them go inside head.
