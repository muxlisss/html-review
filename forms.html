Chapter 6

Forms

Forms collect information from visitors.

Medium

<form>, <label>, <input>

Definition

<form> groups fields, <label> names a field and <input> is a field the user fills in.

Attributes

Attribute Role
action Where the data is sent
method get or post
type (input) text, email, password, radio, checkbox, number, date, submit
name Field name sent to the server
placeholder Hint text
required Field cannot stay empty

Example (code)

<form action="#" method="post"> <label for="n">Name:</label> <input type="text" id="n" name="n" placeholder="Your name" required> <input type="email" name="mail" placeholder="Email"> <input type="submit" value="Send"> </form>

Example (result)

<select> and <option>

Definition

A drop-down list of choices.

Attributes

Attribute Role
name Field name
value (option) Value sent
selected Default choice

Example (code)

<select name="lang"> <option value="html">HTML</option> <option value="css" selected>CSS</option> </select>

Example (result)

<textarea> and <button>

Definition

<textarea> is a multi-line text field and <button> is a clickable button.

Attributes

Attribute Role
rows / cols Size of the text area
type (button) submit, reset or button

Example (code)

<textarea rows="3" cols="30">Write here</textarea><br> <button type="button">Click me</button>

Example (result)


<fieldset> and <legend>

Definition

<fieldset> groups fields in a box and <legend> gives it a title.

Attributes

Attribute Role
disabled Disables all fields inside

Example (code)

<fieldset> <legend>Gender</legend> <input type="radio" name="g" id="m"><label for="m">Male</label> <input type="radio" name="g" id="f"><label for="f">Female</label> </fieldset>

Example (result)

Gender

Quick Recap

form wraps the fields, label names them, input, select and textarea collect data, and button sends it.
