Chapter 3

Links and images

Links connect pages together and images make pages visual.

Easy

<a>

Definition

The anchor tag creates a link to another page, a website, an email address or a place in the same page.

Attributes

Attribute Role
href Destination of the link
target Where to open it (_blank = new tab)
title Tooltip text
id (on target) Creates an anchor to jump to
class / id Global attributes: name the element so CSS can style it

Example (code)

<a href="text.html">Internal link</a><br> <a href="https://www.w3schools.com" target="_blank">External link</a><br> <a href="mailto:hello@example.com">Send an email</a>

Example (result)

External link
Send an email

<img>

Definition

Inserts an image. It has no closing tag.

Attributes

Attribute Role
src Path of the image file
alt Text shown if the image fails
width / height Size in pixels
title Tooltip text

Example (code)

<img src="media/photo.svg" alt="Sample picture" width="200">

Example (result)

Quick Recap

a creates links with href, target="_blank" opens a new tab, and img shows a picture with src and alt.
