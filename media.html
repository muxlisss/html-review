Chapter 7

Multimedia

Add sound, video and other pages inside your page. Put your files in the media folder.

Medium

<audio>

Definition

Plays sound. Use <source> for several formats.

Attributes

Attribute Role
src Audio file
controls Shows play/pause buttons
autoplay Starts automatically
loop Repeats

Example (code)

<audio controls> <source src="media/du-bist-gut-genug.mp3" type="audio/mpeg"> Your browser does not support audio. </audio> <img src="https://media.giphy.com/media/v1.Y2lkPWVjZjA1ZTQ3dWZhbWRldDk2a245YTh3eDFjdXVldXF5endoc3doMjRxZ2Y4Ymp5OSZlcD12MV9naWZzX3NlYXJjaCZjdD1n/5JWwzNwYnyINI2E8Br/giphy.gif" alt="Second animated GIF" width="300">

YouTube video

Definition

Embeds and plays a YouTube video directly on the page.

Attributes

Attribute Role
src YouTube video address
controls Shows video controls
width / height Video size
title Accessible video description

Example (code)

<iframe src="https://www.youtube.com/embed/BzYMFd-lQL4" width="560" height="315" title="YouTube video" allowfullscreen></iframe>

Example (result)

<iframe>

Definition

Shows another web page inside your page.

Attributes

Attribute Role
src Address of the page
width / height Size
title Describes the content

Example (code)

<iframe src="text.html" width="300" height="150" title="Text page"></iframe>

Example (result)

<figure> and <figcaption>

Definition

<figure> groups media and <figcaption> gives it a caption.

Attributes

Attribute Role
class / id Global attributes: name the element so CSS can style it

Example (code)

<figure> <img src="media/front.jpg" alt="Sample" width="200"> <figcaption>Figure 1: Sample picture</figcaption> </figure>

Example (result)

Remote GIF image

Definition

An animated GIF can be displayed directly from an online image URL.

Attributes

Attribute Role
src URL of the online GIF
alt Alternative text for accessibility
width Displayed image width

Example (code)

<img src="https://media.giphy.com/media/v1.Y2lkPWVjZjA1ZTQ3c3Rlajhvcmxnd3U4eTkwcjh1bHZ4eW5sMHAwNTBtb2s1aGRqajExciZlcD12MV9naWZzX3NlYXJjaCZjdD1n/JIX9t2j0ZTN9S/giphy.gif" alt="Animated GIF" width="300">

Example (result)

Quick Recap

audio and video play media with controls, iframe embeds another page, and figure with figcaption adds a caption.
