Chapter 5

Tables

Tables show data in rows and columns.

Medium

<table>, <tr>, <th>, <td>

Definition

<table> creates the table, <tr> a row, <th> a header cell and <td> a data cell.

Attributes

Attribute Role
border (old) Border width, use CSS instead
class / id Global attributes: name the element so CSS can style it

Example (code)

<table> <caption>Marks</caption> <thead> <tr><th>Name</th><th>Score</th></tr> </thead> <tbody> <tr><td>Ali</td><td>15</td></tr> <tr><td>Sara</td><td>18</td></tr> </tbody> </table>

Example (result)

Marks
Name Score
Ali 15
Sara 18

colspan and rowspan

Definition

They merge cells across columns or rows.

Attributes

Attribute Role
colspan Number of columns a cell covers
rowspan Number of rows a cell covers

Example (code)

<table> <tr><th colspan="2">Group A</th></tr> <tr><td rowspan="2">Team</td><td>Ali</td></tr> <tr><td>Sara</td></tr> </table>

Example (result)

Group A
Team Ali
Sara

Quick Recap

table builds the grid, tr is a row, th a header cell and td a data cell. colspan and rowspan merge cells.
